# ONS labour-market data

- `ons_uk_labour_market_clean.csv` – 666 rolling three-month observations, Jan–Mar 1971 to Jun–Aug 2026.
- Contains activity, employment, unemployment and inactivity rates for people aged 16+ and 16–64.
- The file has been cleaned for analysis and contains no extra row-index field.

See the [project README](../README.md) for scope, interpretation and next steps.
