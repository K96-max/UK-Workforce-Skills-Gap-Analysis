# Data files

This folder contains prepared analysis outputs derived from the UK Employer Skills Survey 2024.

| File | Purpose |
|---|---|
| `industry_analysis_2024.csv` | Industry-level skills gap and vacancy measures |
| `regional_analysis_2024.csv` | Regional skills-shortage vacancy measures |
| `training_analysis_2024.csv` | Industry training participation and skills-gap comparison |

The original survey file is not included in this folder. Refer to the project README for methodology, data limitations and interpretation notes. Unavailable survey codes were treated as missing rather than zero.
