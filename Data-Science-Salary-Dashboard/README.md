# Data Science Salary Dashboard (Excel)

## Overview
An interactive Excel dashboard exploring job-posting and salary data for data and analytics roles. The workbook includes a source-data sheet, dashboard controls, and supporting lookup/calculation sheets.

## Workbook contents
- **Data** — 32,672 job-posting records with job title, location, platform, schedule type, remote-work indicator, posting date, country and salary fields.
- **Salary_Dashboard** — dashboard view with filters for job title, country and employment type.
- **Jobs, Country, Type and Platform** — supporting summaries and calculation areas.
- **Data Validation** — lists used to support dashboard selections.

## Questions this dashboard can help explore
- How do salary levels vary by data/analytics job title?
- How do salaries differ by country and employment type?
- Which job platforms contribute the most postings for the selected criteria?
- How can interactive filters help users explore a large job-posting dataset?

## Tools demonstrated
- Microsoft Excel
- Structured tables and formulas
- Dashboard filters / data validation
- Salary summaries and interactive reporting

## Important notes
This is a data-science labour-market project, not an HR employee-data project. It is included as an additional Excel and dashboard example alongside the People Analytics portfolio.

The workbook is retained in its original format. Review formulas and refresh behaviour in desktop Excel before presenting it. The data appears to contain international job postings and should not be interpreted as a UK salary benchmark without filtering and validating the geography and salary units.
