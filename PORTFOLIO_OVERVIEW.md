# People Analytics & HR Data Portfolio

This repository collection demonstrates an evolving portfolio focused on **People Analytics, HR Data Analysis, HRIS / Workday reporting and workforce insights**.

## Featured projects

### 1. [IBM HR Analytics – Employee Attrition](https://github.com/K96-max/IBM-HR-Analytics-Employee-Attrition)
Python, Pandas, MySQL, SQL and Tableau. Explores attrition patterns by department, role, overtime, age and length of service using a simulated 1,470-record dataset.

### 2. [UK Workforce Skills Gap Analysis](README.md)
Python, Pandas, Matplotlib and Tableau. Analyses the UK Employer Skills Survey 2024 across industries and English regions, including training and skills-gap measures.

### 3. [UK Labour Market Intelligence](UK-Labour-Market-Intelligence/README.md)
ONS labour-market time series, cleaned dataset and MySQL practice. Dashboard and full analysis documentation are still in progress.

## Skills demonstrated

- **HR and workforce context:** employee attrition, retention, skills shortages, training and workforce planning.
- **Data preparation:** Python, Pandas, data inspection, data types, missing values and duplicate checks.
- **Querying:** MySQL and SQL aggregations, grouping and comparisons.
- **Reporting:** Excel learning and practice, Tableau visualisation and dashboard development.
- **Communication:** business questions, findings, limitations and practical HR implications.

## Work in progress

Recruitment funnel / hiring analytics is a planned next portfolio project. The source practice files are not currently available in this repository, so it is not presented as a completed project. Dashboard screenshots, packaged Tableau workbooks and additional Excel evidence will be added as they are completed.

## Portfolio principle

Projects use public or simulated data only. No confidential employer, client, employee or candidate information should be published.
